解説資料

受付・呼び出し・表示・お客様スマホの 4 種類の端末を 1 つの Web アプリでまかない、 操作した瞬間に全端末へリアルタイムで反映される順番待ちシステムです。 このサイトでは、その設計・仕様・アーキテクチャ・使われている技術をまとめて解説します。

TanStack Start / Router TanStack DB ElectricSQL Hono + tRPC PostgreSQL 17

このアプリの 3 つの特徴

リアルタイム同期

呼び出し端末で「呼び出す」を押すと、表示端末とお客様のスマホに即座に反映されます。ポーリングや再読み込みは不要です。

イベントソーシング

受付の「状態」は保存しません。「呼び出した」「完了した」という出来事（イベント）だけを追記し、現在の状態はそこから計算します。

1 リポジトリで全端末

端末ごとに別アプリは作りません。違いは URL（画面）だけで、データ・同期・状態計算のしくみは全端末で共通です。

クイックスタート

詳しい手順はリポジトリの README.md を参照してください。おおまかな流れは次のとおりです。

ツールを入れるmise install
pnpm install
環境変数.env を作成し、IP アドレスなどを設定
HTTPS 化pnpm generate:caddy
caddy run
DB と Electricdocker compose up -d とマイグレーション
開発サーバーpnpm dev（Vite と tRPC を同時起動）

ブラウザで https://queue-app.localhost を開くとホーム画面が表示されます。
